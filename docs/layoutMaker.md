# レイアウトメーカー(layout-maker.html)

最終更新:2026-10-22。ツール共通の決まりは [Tools.md](Tools.md)、部品の名前は [htmlParts.md](htmlParts.md)

パーツ台帳の部品を画面の上に自由に置いて、「どこに何があるか」を AI に渡す文章・配置図にするツール。1ファイル(CSS・JS もページの中)。テーマはみかん。

## 画面
- 左(☂ レイヤー):上「追加」= 部品のボタン(骨組み・入れ物・ボタン・選ぶ・入力・一覧・お知らせ)。押すと見えている所の真ん中に、ドラッグして画面の上で離すとそこに置く(指は押すだけ)。下「階層」= 置いた部品の木(番号は文章・配置図と同じ。ダブルクリックで名前を変える)
- 真ん中:上に「PC 1280×800 / タブレット 768×1024 / スマホ 375×812」・マス目・戻す/やり直す・倍率(真ん中の % を押すと幅に合わせる。Ctrl+ホイール)。画面の枠の下にピンクの点線 = 1画面の下のはし(部品を下に置くと枠がのびる)
- 右(✿ 詳細):タブ「詳細・画面・AIに渡す」
  - 詳細:1つ選ぶと 名前・文字(「、」で区切ると並ぶ部品あり)・メモ・x/y/幅/高さ・「幅が変わったとき」(左寄せ・真ん中・右寄せ・横いっぱい)・奥へ/手前へ・複製・消す。何枚か選ぶと「そろえる」(左・真ん中・右・上・真ん中・下・横/縦に等間隔・幅をそろえる)
  - 画面:画面の名前・大きさ・マス目の大きさ(なし/4/8/16)・ぜんぶ消す
  - AIに渡す:「AIプロンプトコピー」・「配置図をコピー」・「配置図を PNG で保存」・「中身を見る」(文章をその場で見る)
- 操作:ドラッグで動かす(Alt で吸い付かない)、ガイド線に吸い付く(下の「しくみ」)、8つのつまみで大きさ、何もない所をドラッグで囲んで選ぶ、Shift/Ctrl+押すで足す、矢印(Shift で大きく)、Delete、Ctrl+Z/Y/D/C/V/A、Esc

## しくみ(JS)
- 部品の種類:`KIND_LIST`(台帳の名前 `name`・クラス `cls`・ワイヤーフレームの形 `wf`・置いたときの大きさ・`box`(入れ物)・`list`(「、」で並ぶ)・`anchor`・`at`)。グループの色は `GROUPS`
- データ `doc`:`{ title, w, h, snap, grid, seq, items }`。テーマは持たない(AI が Base.md の決まりで選ぶ。2026-10-22 に欄を消した)。部品 `{ id, kind, name, named, x, y, w, h, text, memo, anchor }`。並び順 = 奥から手前。sessionStorage `layoutmaker:v1`
- **入れ子は保存しない**:入れ物(`box`)の中にすっぽり入っている部品は、その中身(`parentOf` / `tree`)。いちばん小さい入れ物が親。`normalize` で子を親より手前に並べ直す。入れ物を動かす・消す・複製すると中身も一緒(`withKids`・`topSelected`)
- 吸い付くガイド線:動かす・大きさを変えるとき、画面の左・真ん中・右/上・真ん中と、ほかの部品の左・真ん中・右/上・真ん中・下に、見た目で `GUIDE_PX`(6px)以内なら合わせて、ピンクの線(`.guide`)を出す。マス目より先。まとめて動かすときは全体の外側の四角で合わせる(`guideTargets`・`nearest`・`snapEdge`・`showGuides`)。マス目の線は吸い付き「なし」でも 8px より細かくしない
- すき間をそろえる(動かすときだけ):同じ行(縦が重なる)・同じ列(横が重なる)の部品とのすき間が、①その行・列にもうあるすき間と同じ ②前後の部品のちょうど真ん中 になる所に吸い付き、そろったすき間にピンクの線と数字(`.gapm`)を出す。外周・中心の線と近い方を使う。相手は動かすものと、それを囲む入れ物以外(`gapSnap`)
- 幅を変える(`setScreen`):部品の `anchor` に合わせて、親(無ければ画面)の中で横に動く・伸びる。親からはみ出す分は親の中に収める。縦はそのまま
- 文章(`buildPrompt`):`layoutOrder` で上から順(縦が重なる兄弟は `rowsOf` で「横に並ぶ」にまとめ、すき間も書く)。番号は `numbering`(階層・配置図と同じ)
- 配置図(`renderImage`):canvas に四角・番号・名前・文字。幅 800px 未満は 2 倍で書き出す
- 元に戻す:`snapshot` / `commit(before)`(200回まで)
