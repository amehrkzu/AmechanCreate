# 枠エディタ・シンボルエディタ(characa/frame-editor.html・symbol-editor.html)

最終更新:2026-10-22。キャラカ本体は [CharacterCard.md](CharacterCard.md)、配置の決まりは [Tools.md](Tools.md)

キャラカのオリジナル枠(パネルの飾り)と、オリジナルのシンボル(図形の要素)を描く別ページ。JS はどちらも `frame-editor.js`(シンボルエディタは `<body data-editor="symbol">` → `SYMBOL_MODE`)。描いたものは `frames.js` で描く(キャラカと共通)。

## 枠の4つの部品(上の選択欄で切り替え)
| 部品 | 描くマス | カードでの使われ方 |
|---|---|---|
| 角の飾り(`corner`) | 100×100 | 左上に描くと、4つの角に反転してコピー |
| 辺の模様(`edge`) | 100×50 | 辺に沿って繰り返す。大きさ・すき間はスライダー(`edgeSize` / `edgeGap`) |
| 土台の角(`base` → `def.baseCorner`) | 100×100 | 左上の角の輪郭を自分で描く → 4つの角に反転し、まっすぐつないでパネルの輪郭(`customBaseOutline`) |
| 枠線(`border`) | 100×100、真ん中の横線 y=50 が枠線 | 色・太さ(`def.border.w`。パネルの短い辺の 1/200)。置いた図形は輪郭に沿って一周並ぶ(すき間なし。`drawBorderPattern`) |

- 置ける図形:丸・四角・ひし形・ハート・星。線は点をなめらかにつなぐ(アイコンメーカーと同じ描き方)
- 切り抜き(`cut: true`):前に描いたもの(パネルの塗り・枠線も)を透明にする。`drawIsolated` で別 canvas に描いて重ねる。土台の角にはない
- 色の欄はない。色はキャラカの配色で決まる(最初からすべて `@accent`)
- 編集マス:編集していない部分をうすく重ねる(`renderContext`)、パネルの内側は `PANEL_TINT`(0.5×0.45)の濃さ
- 操作:拡大縮小 25%〜800%(「－ 100% ＋」・ホイール・2本指)、線の上をクリックで点を足す、Alt+点のクリックで角⇔なめらか、最後に置いた点を押すと描き終わり
- レイヤー(左のサイドバーの「階層」):ドラッグで並べ替え(指は長押し 400ms で行が浮く `.lifted`)、▲▼でも。名前の番号は `p.no` で固定、ダブルクリックで名前の変更(`p.name`)

## シンボル
- データ:`{ id, name, w, h, symbol: { paths } }`(w・h は描くマスの大きさ。「マスの形」で縦横比を選ぶ)。保存先は `characa:symbols`(`loadSymbols`)
- キャラカの要素 `symbol` は箱に合わせて伸び縮みし、色は要素ごと(`drawSymbol`)

## キャラカとの行き来
- 保存すると `index.html?frame=u:id`(その枠が選ばれる)/ `index.html?symbol=id`(新しく作ったときは `&add=1` でカードに置く)へ戻る。オリジナル枠は `characa:frames`
- キャラカの書き出し JSON に、使っている枠・シンボル(`customFrames` / `customSymbols`)が入る。読み込むと、このブラウザに足される
