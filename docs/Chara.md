# キャラ系(基盤)— キャラクター紹介・関係辞典に共通

最終更新:2026-10-21

- 個人で楽しむためのページ。データは Google スプレッドシートで管理し、**コミットしなくても更新が反映される**ことを重視している
- キャラクター紹介([Chara_1.md](Chara_1.md))と関係辞典([Chara_2.md](Chara_2.md))は**別物**。スプレッドシートも Apps Script も分けている(ユーザーの指定)
- どちらもテーマは「いちご」系

## 全体の仕組み
- Apps Script の `doGet` がシートとドライブの画像を JSON にして返し、HTML が fetch して表示する
- HTML の `API_URL` に Apps Script の **`/exec` URL** を設定する(`/dev` はテスト用で、作成者しか開けないので不可)
- `API_URL` が空のときは、HTML の中の `SAMPLE_DATA` で表示する
- 「ウェブに公開」(pubhtml)は**使わない**
- データの変更は、シートを保存するだけで反映される。**スクリプトのコードを変えたときだけ**、「デプロイを管理」→ 鉛筆アイコン →「新バージョン」で更新する(URL は変わらない)
- 値の取り方:キャラ紹介は `getDisplayValues()`(日付などはシートの表示どおりの文字)、関係辞典は `getValues()`

## 画像
- 2通りの設定方法がある。B列を優先する
  1. `IMAGE_FOLDER_ID` のフォルダーに、キャラ名と同じファイル名で画像を置く(例:`キャラA.png`)。拡張子を除いた名前で照合する
  2. シートの**B列**に、ドライブの共有リンクか画像の URL を貼る
- **B列は画像に固定**(Apps Script が「A列 = 名前、B列 = 画像」として読む)。ほかの列は C列より右に置く。B列がずれたときの直し(`fixColumns()`)はキャラ紹介だけにあり、関係辞典にはない
- ドライブのリンクは `https://drive.google.com/thumbnail?id=ID&sz=…` に変換して表示する。Google 公式の URL ではないので、将来使えなくなる可能性がある
- フォルダー・ファイルは「リンクを知っている全員」が閲覧できる設定にしておく
- `<img referrerpolicy="no-referrer">` を付けている。読み込みに失敗したら、名前の1文字目を表示する

## デザイン共通
- ピンク(`--accent: #ff6f9c`)と紫(`--accent2: #b58cff`)のグラデーション
- 表示が切り替わるときにポップアニメーション(`.pop`)
- 読み込み中は「ぐるぐる」(パーツ台帳の `.spinner` をページの中に写したもの)+「読み込み中…」

## やりたいこと(データが8割くらいそろってから)
- **キャラ紹介と関係辞典をつなぐ**(2026-10-19 にユーザーが希望)
  - プロフィールの下に「このキャラの関係」として、関係辞典に登録してある相手を顔アイコンで並べる。押すと、関係辞典のその2人のページへ飛ぶ
  - 関係辞典の側からも、それぞれのキャラのプロフィールへ飛べるようにする(`profile.html#キャラ名`)
  - キャラ紹介のキャラ名と、関係辞典の「名前」シートのキャラ名がそろっている必要がある(違うときの対応を決める)

## ユーザーについて
- 会社の Google アカウントだと「全員」に公開できない可能性がある。その場合は個人アカウントを使うよう案内する
- シートの更新日は、今は手で入れる(Ctrl + ;)。自動にするなら `onEdit`(「拡張機能」→「Apps Script」に貼る。デプロイし直しは不要)。コードは未設置
