## シート構成
- 「**プロフィール**」シート:A列 名前 | **B列 画像(固定)** | C列以降は自由項目
  - 1行目の見出しが、そのまま項目名になる。見出しが空の列は無視する
  - 中身が空の項目は表示しない。全部空なら「プロフィールはまだ準備中です」
  - 今の項目:なまえ・別名・愛称・種族・性別・年齢・ジョブ・所属・すきなもの・きらいなもの・体質・超える力・来歴・備考 など
  - **特別な見出し**(どれもプロフィールの項目としては表示しない)
    | 見出し | 書くもの | 動き |
    |---|---|---|
    | 隠し | 何か書く(例:〇) | 隠しキャラにする(下の「隠しキャラ」) |
    | カラー | 色コード(`#88ccff`)か色の名前(`skyblue`) | 選んだとき、ページの色がその色になる |
    | 背景 | ドライブの共有リンクか画像の URL | 選んだとき、ページの背景がその画像になる。フォルダーのファイル名では指定できない |
    | 更新日 | 日付(2026/10/19・2026-10-19・2026年10月19日 のどれでも) | 今日から14日以内なら NEW(`NEW_DAYS`) |
    | 画像 | (B列がずれたとき用) | B列に画像の URL がないとき、この項目の URL を顔アイコンに使う |
- 「**補足**」シート:A列 名前 | B列 見出し | C列 本文 | D列 画像
  - 1行=1ブロック。同じキャラの行はシートの上から順に表示。見出し・本文・画像はどれも空欄にできる
  - 画像欄には、フォルダーのファイル名(拡張子あり・なしどちらでも)か、共有リンク・画像の URL

## 画面の仕様
### キャラクターボタン(スマブラのキャラ選択風)
- 形:UIパーツメーカーで作った「ひし形」(右に傾いた平行四辺形。点 (10,10)(160,10)(190,90)(40,90)、マス 200×100)。クラス `.ub-chara-slant`
  - ボタン(`<button class="char-btn ub-chara-slant">`)は入れ物で、中身の `.slant-body` を `clip-path: polygon(5% 10%, 80% 10%, 95% 90%, 20% 90%)` で切り抜く。NEW マークは切り抜きの外(ボタンの左上にはみ出して)に乗せる
  - 高さは 50px に固定、形の上下は 5px ずつ内側。枠線なし・影なし・のせると浮く(-3px)・押すと沈む
  - 選んでいるキャラ(`aria-pressed="true"`)はキャラの色で塗る
- 顔アイコン:同じ傾きの平行四辺形。ボタンの左の斜めの辺にぴったり付ける
  - 傾きはボタンの幅で変わるので、`fitSlant()` が測って `--edge-x`(位置)・`--slant`(傾き)を入れる(ResizeObserver で測り直す)
  - 顔アイコンは形より上下 2px・左 4px 大きく置き、はみ出しは `.slant-body` の切り抜きで消す(拡大率 75% などで すき間 が出ないように)。見える幅はおよそ 50px
  - 画像がないキャラは、名前の1文字目+うすいキャラ色(`--face-bg`)
- 並べ方(`.char-list--packed`。外すと、ふつうの並べ方に戻る):
  - ボタンの幅は 270px にそろえ(`--pw`)、となりと 25% 重ねて、すき間なく並べる。段どうしも 10px 重ねる
  - 段の人数は「多い・少ない」の交互(例:4・3・4・3…)。いちばん下の段は3人以上(`rowSizes()`)。ぴったり合う並べ方を優先。どうしても無理なら下の段の人を上の少ない段へ移す
  - 1段に2人までしか入らないとき(スマホ)は 2・1 の交互で、いちばん下を2人に
  - 画面の幅が変わって1段の人数が変わると並べ直す(`layoutRows()`)
  - ※キャラ一覧の幅は今 `min(880px, 100%)`。「外側の余白を多くしない」([Base.md](Base.md))に合わせて広げるかは未定
- 隠しキャラ:「隠し」に何か書いたキャラはボタンを出さない。一覧の下に透明な文字で名前を書いておき、ドラッグで文字を選ぶ(反転させる)と見える → 押すと開く。URL の `#キャラ名` で開いたときも見つけた扱い
- NEW マーク:「更新日」が14日以内のキャラのボタン(左上)とプロフィールの名前の横

### 絞り込み
- 一覧の右上の「絞り込み」ボタン → 別ウィンドウ(`<dialog>`)。チップを押すと、その場で一覧も絞り込まれる。「ぜんぶ外す」「決定」「×」・外側・Esc
- 絞り込み中は、ボタンがキャラの色になり、横に「女(9人)」のように条件と人数
- 列と値の分け方(`FILTERS`):
  - 種族:種族の一覧(`RACES` = ヒューラン・エレゼン・ララフェル・ミコッテ・ルガディン・アウラ・ロスガル・ヴィエラ・エレダイト)と見比べる(アウラ・レン → アウラ、ラヴァ・ヴィエラ → ヴィエラ)。一覧にない種族(斧・ドラゴン族など)は「その他」(いちばん最後)
  - 性別:「・」のうしろ(トランスジェンダー・男 → 男)
  - ジョブ:「・」などで区切って1つずつ
- 同じ列の中は「どれか」、ちがう列どうしは「ぜんぶ」

### プロフィール欄・補足
- ボタンを押すと、URL の最後に `#キャラ名` が付く(そのURLで直接開ける)
- 押して選んだとき、プロフィール欄が画面に見えていなければ、そこまでスクロール(見えていれば動かさない)
- 前へ・次へ:左右の ‹ › ボタン、キーボードの ← →、スマホの左右スワイプ(絞り込みで消えているキャラ・隠しキャラは飛ばす)
- 項目・補足の本文のリンク(`linkify()`):`https://…` をそのまま書くとリンク、`[文字](https://…)` で文字にリンク。新しいタブで開く。http/https だけ
- 補足ブロック:スクロールして画面に入るとふわっと出る。画像だけ(+見出し)→ 横幅いっぱい / 画像+本文 → 左右に並べる(左右交互。スマホは縦) / 文章だけ → カード。画像を押すと拡大表示(外側か Esc で閉じる)

### キャラの色・背景
- 「カラー」の色から、アクセント・見出しのグラデーション・枠・背景のうすい色(`--bg` 16% / `--bg2` 42% / `--bg3` 30%)を作る(`applyCharaColor()`)。`@property` で登録してあるので、ふわっと変わる
- 明るい色(相対輝度 0.45 より上)のキャラ(`<html class="light-color">`):アクセント色の文字・選んでいるボタンの文字を `--accent-deep`(キャラの色の色味のまま、明るさを 3/4、鮮やかさ 1.8倍)にする
- 背景のもわもわ:色の雲3つ(`.mofu i`)が 10秒・13秒・16秒でゆっくり漂う(transform だけなので軽い)。動きを減らす設定では止める
- 「背景」の画像:画面全体に貼り付け(cover・中央・スクロールしても動かない)。透けさせない。読めたらふわっと出す
- 「色の調整」の欄(CSS のはじめ):`--btn-bg`(選んでいないボタン)/ `--btn-fg`(その文字)/ `--btn-on-bg` / `--btn-on-fg` / `--face-bg`。ここを書き換えると、まとめて変わる
  - 試してやめたもの:補色のボタン、段ごとの黒い横帯
