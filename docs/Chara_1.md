## シート構成
- 「**プロフィール**」シート:A列 名前 | **B列 画像(固定)** | C列以降は自由項目
  - 1行目の見出しが、そのまま項目名になる。見出しが空の列は無視する
  - 中身が空の項目は表示しない。全部空なら「プロフィールはまだ準備中です」
  - 今の項目:なまえ・種族・性別・年齢・ジョブ・すきなもの など
  - **特別な見出し**(どれもプロフィールの項目としては表示しない)
    | 見出し | 書くもの | 動き |
    |---|---|---|
    | 隠し | 何か書く(例:〇) | 隠しキャラにする(下の「隠しキャラ」) |
    | カラー | 色コード(`#88ccff`)か色の名前(`skyblue`) | 選んだとき、ページの色がその色になる |
    | 背景 | ドライブの共有リンクか画像の URL | 選んだとき、ページの背景がその画像になる。フォルダーのファイル名では指定できない |
    | 更新日 | 日付(2026/10/19・2026-10-19・2026年10月19日 のどれでも) | 今日から14日以内なら NEW(`NEW_DAYS`) |
    | 画像 | (B列がずれたとき用) | B列に画像の URL がないとき、この項目の URL を顔アイコンに使う |
- 「**補足**」シート:A列 名前 | B列 見出し | C列 本文 | D列 画像
  - 1行=1ブロック。同じキャラの行はシートの上から順に表示。見出し・本文・画像はどれも空欄にできる
  - 画像欄には、フォルダーのファイル名(拡張子あり・なしどちらでも)か、共有リンク・画像の URL

## 画面の仕様
### キャラクターボタン(スマブラのキャラ選択風)
- 形は右に傾いた平行四辺形(`.ub-chara-slant`、中身の `.slant-body` を clip-path で切り抜く)。顔アイコンはボタンの左の斜めの辺に付ける(`fitSlant()` が傾きを測る)。選んでいるキャラ(`aria-pressed="true"`)はキャラの色で塗る
- 画像がないキャラは、名前の1文字目+うすいキャラ色(`--face-bg`)
- 並べ方(`.char-list--packed`):となりと重ねて、すき間なく並べる。段の人数は「多い・少ない」の交互で、いちばん下の段は3人以上(スマホは 2・1 の交互)。`rowSizes()` が人数を決め、`layoutRows()` が幅の変化で並べ直す
- 隠しキャラ:「隠し」に何か書いたキャラはボタンを出さない。一覧の下に透明な文字で名前を書いておき、ドラッグで文字を選ぶ(反転させる)と見える → 押すと開く。URL の `#キャラ名` で開いたときも見つけた扱い
- NEW マーク:「更新日」が14日以内のキャラのボタン(左上)とプロフィールの名前の横

### 絞り込み
- 一覧の右上の「絞り込み」ボタン → 別ウィンドウ(`<dialog>`)。チップを押すと、その場で一覧も絞り込まれる。絞り込み中は、ボタンの横に「女(9人)」のように条件と人数
- 列と値の分け方(`FILTERS`):種族は `RACES` の一覧と見比べ(アウラ・レン → アウラ)、一覧にない種族は「その他」(いちばん最後)。性別は「・」のうしろ。ジョブは「・」などで区切って1つずつ
- 同じ列の中は「どれか」、ちがう列どうしは「ぜんぶ」

### プロフィール欄・補足
- ボタンを押すと、URL の最後に `#キャラ名` が付く(そのURLで直接開ける)。プロフィール欄が見えていなければ、そこまでスクロール
- 前へ・次へ:‹ › ボタン、← →、スマホの左右スワイプ(絞り込みで消えているキャラ・隠しキャラは飛ばす)
- 本文のリンク(`linkify()`):`https://…` か `[文字](https://…)`。新しいタブで開く
- 補足ブロック:画像だけ → 横幅いっぱい / 画像+本文 → 左右に並べる(左右交互。スマホは縦) / 文章だけ → カード。画像を押すと拡大表示

### キャラの色・背景
- 「カラー」の色から、アクセント・グラデーション・背景のうすい色(`--bg` / `--bg2` / `--bg3`)を作る(`applyCharaColor()`)。明るい色のキャラは `<html class="light-color">` で、文字を `--accent-deep` にする
- 背景のもわもわ:色の雲(`.mofu i`)がゆっくり漂う。動きを減らす設定では止める
- 「背景」の画像:画面全体に貼り付け(スクロールしても動かない)(`applyCharaBg()`)
- 「色の調整」の欄(CSS のはじめ):`--btn-bg` / `--btn-fg` / `--btn-on-bg` / `--btn-on-fg` / `--face-bg`。ここを書き換えると、まとめて変わる
