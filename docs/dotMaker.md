# ドット絵メーカー(dot-maker.html)

最終更新:2026-10-21。ツール共通の決まりは [Tools.md](Tools.md)

- アプリ用のドット絵を描くツール。16×16 などの少ないマスで描いて、1000×1000 px などの大きな PNG で、くっきり書き出す(2026-10-21 に作った)
  - きっかけ:ふつうのドット絵ツールの絵は小さすぎて、拡大するとぼやける
- 1ファイルで完結(CSS・JS もページの中)。新しいページなので `<html data-theme="mikan">` + `ui/kit.css`。`ui/layer-drawer.css` / `.js`、`ui/site-header.js` も読み込む
- トップの「ツール」に カード(アイコン:四角いマスのハート。説明「ドット絵を高画質で出力する」)

## 画面
- 広い画面:左の列(追加+色)/ 真ん中の描くマス / 右の列(マス・書き出し)。狭い画面では左右とも引き出し(☂ レイヤー / ✿ 詳細)
  - 左の「追加」:✏️ ペン(B)/ 🧽 消しゴム(E。右クリックでも消える)/ 🪣 塗りつぶし(G)/ 💧 スポイト(I)
  - 左の「色」:いまの色・パレット 16 色・使っている色(絵の中の色が自動で並ぶ)
  - 真ん中の上:マス目の表示(まるスイッチ)・戻す・やり直す(Ctrl+Z / Ctrl+Y)
  - 右の「マス」:8×8〜64×64 のチップ、横×縦(1〜128)、ぜんぶ消す。大きさを変えると、絵は真ん中に置いたまま、まわりを足す・けずる(戻せる)
  - 右の「書き出し」:長い辺の大きさ(最初は 1024。16〜4096 px。チップ 256/512/1000/1024/2048)、背景を塗る(しなければ透明)、ファイル名、PNG で保存
- レイヤーは1枚だけ(階層の一覧はまだない)

## しくみ
- 絵は「横 × 縦のマスに色(#rrggbb。空は透明)」の一覧。作りかけはそのタブを開いている間だけ覚える(sessionStorage `dotmaker:v1`)
- 書き出しは、小さい絵を拡大するのではなく、書き出す大きさのキャンバスに、マスを**整数の境目**(`Math.round(i × 大きさ ÷ マス数)`)で直接塗る。1000 ÷ 16 = 62.5 のように割り切れなくても、マスは 62px と 63px になるだけで、色のにじみは出ない
- 画面の描くマスも、端末の細かさ(devicePixelRatio)に合わせて同じ方法で描く
- ペンは、速く動かしてもすき間ができないよう、前の点から今の点まで線でつなぐ(ブレゼンハム)。塗りつぶしは上下左右につながった同じ色

## コードの中の地図(dot-maker.html の JS)
- 定数:`KEY`(保存の名前)、`MAX_GRID`(マス数の上限 128)、`PALETTE`(パレット16色)、`GRID_PRESETS`(マスのチップ)、`OUT_PRESETS`(書き出しのチップ)
- 状態 `doc`(`blank()` が初期値):`w`・`h`(マス数)、`px`(長さ w×h の配列。`px[y * w + x]` が色、`""` は透明)、`color`(いまの色)、`grid`(マス目の表示)、`out`(長い辺の px。初期値 1024)、`bgOn`・`bg`(背景)、`name`(ファイル名)
  - `doc` を丸ごと sessionStorage に入れる(`save()`。0.3 秒まとめて)。`load()` で読み戻す。項目を足したら `blank()` に初期値を書けば、古い保存にも自動で足される
- そのほかの状態:`tool`(`"pen" | "eraser" | "fill" | "pick"`)、`hover`(マウスがのっているマス)、`stroke`(描いている途中)
- 元に戻す:`picture()`(絵だけ = w・h・px を JSON に)を `undoStack` / `redoStack` に積む。**1回の線で1つ**(pointerdown で前の絵を取っておき、pointerup で変わっていたら `pushUndo`)。色や書き出しの設定は戻す対象ではない
- 絵が変わったあとは `afterPictureChange()`(ボタン・マス数の欄・使っている色・書き出しの大きさ・キャンバスを全部描き直して保存)
- `edges(n, total)`:n マスを total px に分ける整数の境目。画面(`draw()`)と書き出し(`renderPng()`)の両方で使う。**ぼやけない仕組みの中心なので、ここを拡大(drawImage や CSS の拡大)に置き換えない**
- 画面:`resizeCanvas()`(箱の大きさ × devicePixelRatio にキャンバスを合わせる。ResizeObserver から呼ぶ)→ `draw()`(マス・透明の市松模様・マス目の線(8マスごとに濃い線)・マウスの下の枠)
- 描く:`cellAt(e)`(マウスの位置 → マス)、`setPx`、`lineTo`(ブレゼンハム)、`floodFill`。キャンバスの pointerdown / pointermove / pointerup
- 道具と色:`setTool(t)`、`setColor(c)`(色を選ぶと、消しゴム・スポイトからペンに戻る)、`renderPalette()`、`renderUsed()`
- マス数:`resizeGrid(w, h)`(真ん中ぞろえで足す・けずる。元に戻せる)、`renderGridUi()`
- 書き出し:`outDims()`(長い辺 = out、短い辺は比で計算)、`renderOutInfo()`、`setOut(n)`、`renderPng()`(新しいキャンバスにマスを塗るだけ)→「PNG で保存」で `toBlob` → `<a download>`
- キー:B / P = ペン、E = 消しゴム、G = 塗りつぶし、I = スポイト、Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y。入力欄にいるときは効かない

## 確認のしかた
- [Base.md](Base.md) の「画面の確認」のとおりに開いて、ページの JS を直接呼んで確かめる
- 書き出しの確認:`renderPng()` のキャンバスを `getImageData` で読み、①大きさが指定どおり(16×16 → 1024×1024、16×10 → 1024×640 など)②色の種類が「塗った色+透明(0,0,0,0)」だけ、を見る。中間の色が1つでもあれば、ぼやけている
- 描く確認:キャンバスに PointerEvent(pointerdown → pointermove → pointerup)を送る。マスの真ん中の座標は `r.left + (x + 0.5) * r.width / doc.w`
