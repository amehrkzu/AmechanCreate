# なんちゃってレイドシュミレーター(raid-sim.html)

最終更新:2026-10-28。ツール共通の決まりは [Tools.md](Tools.md)

- FF14 のオリジナルレイドを、みんなで考えて遊ぶためのツール。ギミックのタイムラインを作り、8人の動き(正規解法)を置いて、再生して確かめる(2026-10-28 に作った)
- 1ファイルで完結。テーマは **ぶどう**(`<html data-theme="budo">`。ツールはみかんが決まりだが、ユーザーの希望)+ `ui/kit.css`・`ui/layer-drawer.*`・`ui/site-header.js`・`ui/scrollbar.css`・`ui/util.js`
- 完成するまでトップにカードは出さない
- みんなに渡す(配布・共有)は、いったん作らない(ユーザーの希望)

## 画面
- 左(☂ レイヤー):上「追加」= 敵(ボス・雑魚。今の時間に出てきて最後までいる)と、ギミックのボタン(円範囲・ドーナツ・直線・扇範囲・十字・塔・頭割り・散開・ノックバック。押すと、今の時間から詠唱が始まる形で足す。敵を選んでいたら、その敵から出す)・そのほか(💬 セリフ。今の時間に出る)。下「階層」= メンバー(MT/ST/H1/H2/D1〜D4。点の数)・敵(出ている秒)・ギミック(発動の秒の順。失敗は ×)・セリフ(出る秒の順)
- 真ん中:上から見たフィールド(北が上。敵は出ている間だけ描く。三角が正面。フィールドマーカー A〜D・1〜4)。上に詠唱バー、下にセリフの帯(名前 + セリフ。重なったら、あとから出たもの)
  - メンバーをドラッグ → **今の時間に「動きの点」** を置く(同じ時間の点があれば動かす)。点と点の間はまっすぐ歩く
  - 敵をドラッグ → 今の時間に敵の動きの点を置く(出てくる時間なら出てくる場所を動かす)。追いかけている間は選ぶだけ
  - 地点のギミック(選んでいる・見えているもの)もドラッグで動かす。マーカーはここでは動かない(戦闘中は動かないので。右のフィールドで置く)
- 真ん中の下:タイムライン(▶ 再生 / ⏮ / 時間 / 速さ ×0.5・×1・×2)。上の段がギミック(詠唱の長さの帯。右はしが発動)、次がセリフの段(帯。重なったら段を分ける)、次が敵ごとの段(出ている間の帯・動きの点・ねらう人の切りかえ ◆)、下がメンバーごとの動きの点
  - 何もない所を押す・ドラッグ → 時間を動かす。ギミック・セリフの帯・点・◆をドラッグ → 時間を変える
- 右(✿ 詳細):付箋タブ「詳細 / フィールド / 結果」
  - 詳細:ギミック = 名前・発動・詠唱・出る場所(敵 / 地点 / メンバー。敵が2体以上なら出す敵)・対象(ねらう人)・向き・大きさ・消す。メンバー = 動きの点の一覧(押すとその時間へ・✕ で消す)・今の場所に点を打つ・点をぜんぶ消す。敵 = 名前・種類・出る / 消える(秒)・歩く速さ・止まる距離・出てくる場所と向き・今の時間から ねらう人(動きの点 / MT…)・ねらう人の切りかえの一覧・動きの点の一覧(向きの欄つき)・今の場所に点を打つ・消す。セリフ = セリフ・話す人(敵 / 名前を書く)・出る(秒)・長さ(秒)・長さを文字の数から決める(切りかえ)・消す
  - フィールド:形(丸 / 四角)・大きさ(半径 m)・長さ(秒)・ぜんぶ消す。小見出し「マーカー」= 表示・元の場所に・小さいプレビュー(床・0 秒にいる敵・マーカー。マーカーをドラッグで動かすと真ん中にもすぐ映る)・マーカーごとの東西・南北(m)の欄
  - 結果:失敗したギミックの一覧(押すとその時間へ)。無ければ「ぜんぶ成功 ✓」
- キー:スペース = 再生・止める、← → = 0.1 秒(Shift で 1 秒)、Delete = 選んでいるギミック・セリフ / 今の時間の点(メンバー・敵)を消す

## しくみ
- 位置は m(ヤルム)。真ん中が (0, 0)、北が -y。向きは北が 0°・時計回り
- 最初の立ち位置(ボスから 5m):北 MT・北東 D1・東 H1・南東 D3・南 ST・南西 D4・西 H2・北西 D2
- 当たりは「発動の瞬間のメンバーの真ん中の点」で調べる。メンバーにつく範囲・ねらう範囲は、詠唱中はメンバーについて動き、発動で止まる
  - ふつうの範囲:中に入った人が「当たる」/ 散開:自分の円は平気、ほかの人の円に入ると当たる / 頭割り・塔:中の人数が足りないと失敗(頭割りが2つ重なった人も当たる)/ ノックバック:飛ばされた先がフィールドの外だと「場外」
- ノックバックの出る場所は 敵 / 地点 / メンバー。メンバーからのときは、半径の中のほかの人だけ飛ばす(中心の人は飛ばされない。2人以上から押されたら押す力を足す)
- ノックバックは、動きの点とは別の「ずれ」。0.5 秒で飛ばされ、次の動きの点に向かって少しずつ戻る(次の点が無ければ、そのまま)
- 敵の動き:0.1 秒(`DT`)ごとの位置と向きを前から順に作る。追いかけるときは、ねらう人へ速さ `speed` で歩き `reach` まで近づき、ねらう人を向く。動きの点に戻ると、そのときの場所から次の点へ歩く(ワープしない)。出る前は出てくる場所、消えたあとはその場所に止まる
- ねらう人の位置はノックバックのずれも入れる。ずれは敵の位置で決まることもあるので、`allPushes` の中で、ノックバックの時間の順に敵の動きを少しずつ進める(`pos` を敵の計算から呼ぶと、ぐるぐる回って止まらない)
- セリフの長さ:「文字の数から決める」がオンなら 2 + 文字数 × 0.15 秒(2〜10 秒。`autoDur`)。長さを書くとオフになる
- 作りかけはそのタブを開いている間だけ(sessionStorage `raidsim:v1`)

## コードの中の地図(raid-sim.html の JS)
- 定数:`ROLES`(メンバーと色)、`SPAWN`(最初の立ち位置)、`MARKS`(マーカー)、`ENEMY_TYPES`(敵の種類・色・大きさ)、`DT`、`KINDS`(ギミックの種類。`at` 出る場所・`aim` ねらえる・`angle` 向き・`nums` 大きさの欄・`def` 初期値)、`NUMS`(大きさの欄の名前と範囲)、`numsOf`(ギミックごとの大きさの欄。メンバーからのノックバックは半径も)、`KB_TIME`・`FLASH`
- 状態 `doc`(`blank()`):`shape`・`size`・`dur`・`marksOn`・`marks`・`players`(メンバーごとの点 `{ t, x, y }`)・`enemies`(`newEnemy`。`id, type, name, appear, vanish(null = 最後まで), x, y, a(出てくる場所と向き), speed, reach, keys { t, x, y, a }, aggro { t, role }`)・`lines`(セリフ。`id, t, text, who(敵の id。null なら name), name, dur, auto`)・`mechs`(ギミック。`id, kind, name, t(発動), cast, at("boss" = 敵), src(出す敵。無ければ1体目), x, y, angle, roles, r, inner, w, len, deg, need, dist`)。そのほか `time`・`playing`・`speed`・`sel`(`{ type: "player" | "enemy" | "mech" | "line", id }`)
- `cache`(`getCache`):ノックバックのずれと敵の動き(`allPushes` が `pushes`・`tracks` を作る。メンバーからのノックバックはほかの人の位置で決まるので、全員まとめて時間の順に調べる)と結果(`results`)。doc を変えたら `changed()` が消して、一覧・詳細・結果・タイムライン・フィールドを描き直す(`changed(true)` は入力中の詳細を作り直さない)
- 位置:`basePos`(点をつなぐ。`along`)→ `pos`(+ ノックバックのずれ `pushAmount`)。点を置く `setKey`
- 敵:`runTrack`(動きを作る)・`trackPos`・`enemyPos`・`enemyOf`(ギミックを出す敵)・`aggroAt`・`enemyShown`。`addEnemy`・`deleteEnemy`・`setEnemyKey`・`setAggro`
- 当たり:`instances`(範囲1つぶんの位置と向き)、`inside`、`evaluate`(1つのギミックの結果)、`results`
- 描く:`drawArena`(背景・床・方眼。真ん中と小さいプレビューで使う)・`drawEnemy`・`drawMark`(どちらも描く先の ctx を受け取る)。`draw`(マーカー・ギミック `drawMech`/`shapePath`/`drawArrows`・詠唱バー・敵・選んだメンバーの道すじ・メンバー)。`view`(m → 画面 px)、`toWorld`
- セリフ:`lineById`・`lineWho`(話す人の名前)・`autoDur`・`addLine`・`deleteLine`。帯は `draw` の中で出す(`#talk`)
- タイムライン:`renderTimeline`(`laneOf(items, start, end)` で帯を重ならない段に分ける。ギミックとセリフで使う。`tlScale` = 1秒の px)、`moveHead`
- 詳細:`renderDetail`(input → `changed(true)`、ボタン → `changed()`)・`renderEnemyDetail`・`renderLineDetail`・`renderAggroNow`(時間を動かすたびに描き直す)、`renderField`(`renderMarkInputs` も)、マーカーのプレビュー `drawMarkMap`(`changed()` でも描く。`markView`・`markAt`)、`renderResults`、`renderLists`

## 決まったこと(ユーザーと決めたこと)
- テーマは ぶどう
- フィールドの形は、丸と四角の両方から選べる
- みんなに渡す(配布・共有)は、いったん作らない
- 名前は「なんちゃってレイドシュミレーター」
- 完成するまでトップにカードは出さない
- マーカーは右のフィールドの小さいプレビュー・数字の欄でだけ動かす(真ん中のフィールドでは動かさない)
- 敵:ボス・雑魚を何体でも置ける。出る・消える時間を決められる。動きの点で動くか、ねらう人を追いかけるかを時間で切りかえる(タンクスイッチもこれ)。速さ・止まる距離は敵ごと
- セリフは、敵か名前を書いた人が話す。フィールドの下の帯に出す。長さは文字の数から自動(あとから変えられる)
- 敵から出る直線・扇・十字の向きは、敵の正面が 0°。動きの点の向きは、点の時間でぱっと変わる。発動のときに敵がいなくても発動する
