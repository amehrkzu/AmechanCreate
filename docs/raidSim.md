# なんちゃってレイドシュミレーター(raid-sim.html)

最終更新:2026-10-29。ツール共通の決まりは [Tools.md](Tools.md)

- FF14 のオリジナルレイドを、みんなで考えて遊ぶためのツール。ギミックのタイムラインを作り、8人の動き(正規解法)を置いて、再生して確かめる(2026-10-28 に作った)
- 1ファイルで完結。テーマは **ぶどう**(`<html data-theme="budo">`。ツールはみかんが決まりだが、ユーザーの希望)+ `ui/kit.css`・`ui/layer-drawer.*`・`ui/site-header.js`・`ui/scrollbar.css`・`ui/util.js`
- 完成するまでトップにカードは出さない
- みんなに渡す(配布・共有)は、いったん作らない(ユーザーの希望)

## 画面
- 上の帯の右:「🎬 動画で保存」。押すと 0 秒から最後までを ×1 で録る(録っている間は「⏹ 録画中 n / 長さ 秒」になり、ほかの操作は止まる。もう一度押すとやめて、保存しない)。録り終わると `raid-sim.mp4`(作れないブラウザでは `raid-sim.webm`)を保存する。映るのは真ん中のフィールドと、詠唱バー・セリフの帯。選んでいる印は映さない。終わったら、元の時間と選んでいたものに戻す
- 左(つまみ「☂ オブジェクト追加」):「追加」だけ = 敵(ボス・雑魚。今の時間に出てきて最後までいる)と、ギミックのボタン(円範囲・ドーナツ・直線・扇範囲・十字・塔・頭割り・散開・ノックバック。押すと、今の時間から詠唱が始まる形で足す。敵を選んでいたら、その敵から出す)・そのほか(💬 セリフ。今の時間に出る)。選ぶのは、フィールド(メンバー・敵・地点のギミック)・タイムライン(帯・段)から
- 真ん中:上から見たフィールド(北が上。敵は出ている間だけ描く。三角が正面。フィールドマーカー A〜D・1〜4)。上に詠唱バー、下にセリフの帯(名前 + セリフ。重なったら、あとから出たもの)。枠の外の右上(枠のすぐ上の行。枠と同じ幅で右寄せ)に ↶ 元に戻す・↷ やり直す(戻せないときは薄い。動画には映らない)
  - メンバーをドラッグ → **今の時間に「動きの点」** を置く(同じ時間の点があれば動かす)。点と点の間はまっすぐ歩く
  - 敵をドラッグ → 今の時間に敵の動きの点を置く(出てくる時間なら出てくる場所を動かす)。追いかけている間は選ぶだけ
  - 地点のギミック(選んでいる・見えているもの)もドラッグで動かす。マーカーはここでは動かない(戦闘中は動かないので。右のフィールドで置く)
- 真ん中の下:再生のバー(音楽プレイヤーの形:⏮ はじめ / ⏪ 5 秒戻る / ▶ 再生(再生中は ⏸)/ ⏩ 5 秒進む / ⏭ 最後。文字は出さず、名前は title。そのあと 時間「今 / 長さ 秒」/ 速さ ×0.5・×1・×2)は1つで、タイムラインは上下2つ(秒の目もり・今の時間の線・横スクロールはそろえて動く)
  - 上:ギミックの段(詠唱の長さの帯。右はしが発動)・セリフの段(帯。重なったら段を分ける)・敵ごとの段(出ている間の帯・動きの点・ねらう人の切りかえ ◆)
  - 下(PT):メンバーごとの動きの点
  - それぞれの右上(秒の目もりの行の右はし)に最小化ボタン(−)。たたむと秒の目もりの行(今の時間の線つき。押す・ドラッグで時間を動かせる)だけになり、左の欄に名前(ギミック / PT)を出す。フィールドの大きさは変わらない。開いているかは覚えない
  - 何もない所を押す・ドラッグ → 時間を動かす。ギミック・セリフの帯・点・◆をドラッグ → 時間を変える
  - ギミック・セリフの帯のはしをドラッグ → 長さを変える。ギミックは左はし = 詠唱の始まり(発動はそのまま)、右はし = 発動(始まりはそのまま)。セリフは左はし = 出る時間(終わりはそのまま)、右はし = 終わり。セリフのはしを動かすと「長さを文字の数から決める」は切れる(長さは 0.5 秒より短くしない)。帯・はしのドラッグ中は今の時間の線がついてくる
  - 敵の出ている間の帯:左はし = 出てくる時間、右はし = 消える時間(いちばん右まで引くと「消えない」。消えない敵も右はしを引くと消える時間ができる)。真ん中 = 出てくる・消える時間を、動きの点・◆ごといっしょにずらす(0 秒と長さからはみ出さない)
  - 帯が細いときは、はしのつかみ所を小さくして、真ん中もつかめるようにする
- 右(✿ 詳細):付箋タブ「詳細 / フィールド」
- 右はしのつまみ「✿ 配置プリセット」(「✿ 詳細」の下):押すと、配置プリセットだけの引き出しが右から出る。画面の幅にかかわらず引き出し(広い画面では、右の列の上に重ねて出す)。狭い画面では、詳細と配置プリセットの引き出しは、片方を開くともう片方がしまう
  - 詳細:ギミック = 名前・発動・詠唱・出る場所(敵 / 地点 / メンバー。敵が2体以上なら出す敵)・対象(ねらう人)・向き・大きさ・消す。メンバー = 動きの点の一覧(押すとその時間へ・✕ で消す)・今の場所に点を打つ・点をぜんぶ消す。敵 = 名前・種類・アイコンの画像(画像を選ぶ / 画像を外す。小さい丸の見本つき)・出る / 消える(秒)・歩く速さ・止まる距離・出てくる場所と向き・今の時間から ねらう人(動きの点 / MT…)・ねらう人の切りかえの一覧・動きの点の一覧(向きの欄つき)・今の場所に点を打つ・消す。セリフ = セリフ・話す人(敵 / 名前を書く)・出る(秒)・長さ(秒)・長さを文字の数から決める(切りかえ)・消す
  - 配置プリセット:押すと、今の時間に 8 人の動きの点を置く(同じ時間の点は置き直す)。決まったもの = 初めの並び・全員集合(ボスの南 5m に、輪にして少しずらす)・ライトパーティ(MT・H1・D1・D3 が東、ST・H2・D2・D4 が西。散開の距離の半分)・8 方向散開(MT 北・D1 北東・H1 東・D3 南東・ST 南・D4 南西・H2 西・D2 北西)。散開の距離はフィールドの半径の 0.75 倍。「今の並びを足す」= 名前を書いて「足す」で、今の時間の 8 人の場所(ノックバックのあと)をプリセットに足す(名前が空なら「プリセット n」。✕ で消す。データと一緒に保存)。名前が1行に収まらないときは「…」で省く(全部の名前は、のせると出る)
  - 戦闘の長さ(秒):再生のバーの長さの数字(点線の下線)を押すと入力欄になる。Enter・外を押す で決める、Esc でやめる(10〜900 秒。今の時間が長さより後ろなら長さに合わせる)。フィールドには置かない
  - フィールド:形(丸 / 四角)・大きさ(半径 m)・ぜんぶ消す。小見出し「マーカー」= 表示・元の場所に・小さいプレビュー(床・0 秒にいる敵・マーカー。マーカーをドラッグで動かすと真ん中にもすぐ映る)・マーカーごとの東西・南北(m)の欄
- キー:Ctrl+Z = 元に戻す、Ctrl+Y・Ctrl+Shift+Z = やり直す(入力欄の中では、欄そのものの元に戻すになる)、スペース = 再生・止める、← → = 0.1 秒(Shift で 1 秒)、Delete = 選んでいるギミック・セリフ / 今の時間の点(メンバー・敵)を消す

## しくみ
- 位置は m(ヤルム)。真ん中が (0, 0)、北が -y。向きは北が 0°・時計回り
- 最初の立ち位置(レイド開始):全員が南にいて、ボスと向き合う。ボスは中央から北へ 3m・南向き。前の列(中央から南へ 8m)= 西から D2・MT・ST・D1、後ろの列(南へ 11m)= 西から H2・D4・D3・H1(東西は担当の向き:H1・D1・D3 が東、H2・D2・D4 が西)。前の形(ボスが中央・北向き)で保存されていて動きの点が無いボスは、読み込むときに今の形に直す
- 当たった・失敗の判定はしない(ユーザーの希望で消した)。メンバー・敵につく範囲・ねらう範囲は、詠唱中はついて動き、発動で止まる。塔・頭割りには、中にいる人数 / 必要な人数を出す(`inside` で数える)
- ノックバックの出る場所は 敵 / 地点 / メンバー。メンバーからのときは、半径の中のほかの人だけ飛ばす(中心の人は飛ばされない。2人以上から押されたら押す力を足す)
- ノックバックは、動きの点とは別の「ずれ」。0.5 秒で飛ばされ、次の動きの点に向かって少しずつ戻る(次の点が無ければ、そのまま)
- 敵の動き:0.1 秒(`DT`)ごとの位置と向きを前から順に作る。追いかけるときは、ねらう人へ速さ `speed` で歩き `reach` まで近づき、ねらう人を向く。動きの点に戻ると、そのときの場所から次の点へ歩く(ワープしない)。出る前は出てくる場所、消えたあとはその場所に止まる
- ねらう人の位置はノックバックのずれも入れる。ずれは敵の位置で決まることもあるので、`allPushes` の中で、ノックバックの時間の順に敵の動きを少しずつ進める(`pos` を敵の計算から呼ぶと、ぐるぐる回って止まらない)
- セリフの長さ:「文字の数から決める」がオンなら 2 + 文字数 × 0.15 秒(2〜10 秒。`autoDur`)。長さを書くとオフになる
- 作りかけはそのタブを開いている間だけ(sessionStorage `raidsim:v1`)

## コードの中の地図(raid-sim.html の JS)
- 定数:`ROLES`(メンバーと色)、`SPAWN`(最初の立ち位置)、`BOSS_SPAWN`(ボスの最初の場所と向き。`newEnemy` と `load` の直しで使う)、`MARKS`(マーカー)、`ENEMY_TYPES`(敵の種類・色・大きさ)、`DT`、`KINDS`(ギミックの種類。`at` 出る場所・`aim` ねらえる・`angle` 向き・`nums` 大きさの欄・`def` 初期値)、`NUMS`(大きさの欄の名前と範囲)、`numsOf`(ギミックごとの大きさの欄。メンバーからのノックバックは半径も)、`KB_TIME`・`FLASH`
- 状態 `doc`(`blank()`):`shape`・`size`・`dur`・`marksOn`・`marks`・`players`(メンバーごとの点 `{ t, x, y }`)・`enemies`(`newEnemy`。`id, type, name, appear, vanish(null = 最後まで), x, y, a(出てくる場所と向き), speed, reach, keys { t, x, y, a }, aggro { t, role }`)・`lines`(セリフ。`id, t, text, who(敵の id。null なら name), name, dur, auto`)・`mechs`(ギミック。`id, kind, name, t(発動), cast, at("boss" = 敵), src(出す敵。無ければ1体目), x, y, angle, roles, r, inner, w, len, deg, need, dist`)。そのほか `time`・`playing`・`speed`・`sel`(`{ type: "player" | "enemy" | "mech" | "line", id }`)
- `cache`(`getCache`):ノックバックのずれと敵の動き(`allPushes` が `pushes`・`tracks` を作る。メンバーからのノックバックはほかの人の位置で決まるので、全員まとめて時間の順に調べる)。doc を変えたら `changed()` が消して、詳細・タイムライン・フィールドを描き直す(`changed(true)` は入力中の詳細を作り直さない)
- 位置:`basePos`(点をつなぐ。`along`)→ `pos`(+ ノックバックのずれ `pushAmount`)。点を置く `setKey`
- 敵:`runTrack`(動きを作る)・`trackPos`・`enemyPos`・`enemyOf`(ギミックを出す敵)・`aggroAt`・`enemyShown`。`addEnemy`・`deleteEnemy`・`setEnemyKey`・`setAggro`
- 範囲:`instances`(範囲1つぶんの位置と向き)、`inside`(中にいるか。塔・頭割りの人数)
- 描く:`drawArena`(背景・床・方眼。真ん中と小さいプレビューで使う)・`drawEnemy`・`drawMark`(どちらも描く先の ctx を受け取る)。敵の画像は `en.img`(data URL)。選んだファイルは `shrinkImage` で `ICON_PX` に縮め、描くときは `enemyImage`(`enemyImages` に読みこんでおき、読めたら描き直す)。`draw`(マーカー・ギミック `drawMech`/`shapePath`/`drawArrows`・詠唱バー・敵・選んだメンバーの道すじ・メンバー)。`view`(m → 画面 px)、`toWorld`
- 配置プリセット:`PRESETS`(決まったもの。`pos()` が { MT: [x, y], … } を返す。`spread` = 散開の距離、`DIR8`・`SQ4`)、`doc.presets`(自分で作ったもの { name, pos })、`applyPreset`(`setKey` で今の時間に置く)、`renderPresets`(`changed()` でも描く)。引き出しは `#presetDrawer`・`#presetHandle`(`.open` を `setPresetOpen` で付け外し。ui/layer-drawer の部品は使わず、このページの CSS `.preset-drawer`・`.preset-handle`)
- 元に戻す:`changed()` のあと 400ms 待って `remember` が doc の JSON を覚える(前と同じなら何もしない。ドラッグ1回・続けての入力が1回分になる)。`hist`(`last` = 今の形、`undo` / `redo`。`UNDO_MAX` = 15 回。メモリだけで、読み込み直すと消える)。`undo` / `redo` は `restore`(doc を入れかえ、選んでいたものが無ければ外す)。ボタンの薄さは `renderUndo`
- 動画:`recordVideo`(`VIDEO_TYPES` の先から使える形式を選ぶ。別の canvas に、毎フレーム `setTime` → 真ん中の canvas を写す → `drawOverlays` で詠唱バー・セリフの帯を、画面の上の位置・色(getComputedStyle)のまま描く。`wrapText` で折り返す。`captureStream(VIDEO_FPS)` を MediaRecorder で録る)。録画中は `rec`(`rec.cancel` でやめる)。キー操作も止める
- セリフ:`lineById`・`lineWho`(話す人の名前)・`autoDur`・`addLine`・`deleteLine`。帯は `draw` の中で出す(`#talk`)
- タイムライン:`renderTimeline`(上 `#tlInnerA`・下 `#tlInnerB` を描く。操作は `tlInners` の両方に同じものを付ける。横スクロールは scroll で相手に写す。最小化は `#tlPartA`・`#tlPartB` の `.open` を付け外し(`renderFold`)。たたんだほうは `renderTimeline` の `fill` で目もりの行だけ描き、左の欄に `data-name` を出す。`laneOf(items, start, end)` で帯を重ならない段に分ける。ギミックとセリフで使う。`tlScale` = 1秒の px。帯の両はしは `edges(w)`(`.tl-edge` `data-edge="l"/"r"`。幅は帯の 1/4 まで)。押した所は `edgeOf` で見分け、`tlDrag.edge` に入れる。敵の帯は `.tl-span` `data-espan`(ドラッグは `tlDrag.type === "espan"`。始めの時間を `appear0`・`vanish0`・`keys0`・`aggro0` に覚えてずらす)。セリフの最短は `LINE_MIN`)、`moveHead`
- 詳細:`renderDetail`(input → `changed(true)`、ボタン → `changed()`)・`renderEnemyDetail`・`renderLineDetail`・`renderAggroNow`(時間を動かすたびに描き直す)、`renderField`(`renderMarkInputs` も)、マーカーのプレビュー `drawMarkMap`(`changed()` でも描く。`markView`・`markAt`)。戦闘の長さ:再生のバーの `#durBtn`(数字は `setTime` で書く)を押すと `durEdit(true)` で `#duration` の欄に変わる

## 決まったこと(ユーザーと決めたこと)
- テーマは ぶどう
- フィールドの形は、丸と四角の両方から選べる
- みんなに渡す(配布・共有)は、いったん作らない
- 名前は「なんちゃってレイドシュミレーター」
- 完成するまでトップにカードは出さない
- 当たり・失敗の判定はしない(「結果」のタブ・赤い帯・赤く光るのは無し)
- タイムラインは上(ギミック・セリフ・敵)と下(PT)の2つに分けて、上下に並べる。PC で下がはみ出すのは、最小化ボタンでたたんで解決する
- 左は「追加」だけにして、階層(一覧)は置かない。つまみは「☂ オブジェクト追加」(ツール共通の決まりでは左は追加 + 階層だが、このツールはユーザーの希望でちがう)
- マーカーは右のフィールドの小さいプレビュー・数字の欄でだけ動かす(真ん中のフィールドでは動かさない)
- 敵:ボス・雑魚を何体でも置ける。出る・消える時間を決められる。動きの点で動くか、ねらう人を追いかけるかを時間で切りかえる(タンクスイッチもこれ)。速さ・止まる距離は敵ごと
- セリフは、敵か名前を書いた人が話す。フィールドの下の帯に出す。長さは文字の数から自動(あとから変えられる)
- 敵から出る直線・扇・十字の向きは、敵の正面が 0°。動きの点の向きは、点の時間でぱっと変わる。発動のときに敵がいなくても発動する
- 敵のアイコンの画像:パソコンのファイルから選ぶ。敵1体ずつ。今の丸の形に切り抜き、枠の色(種類の色)は残す。画像のときは名前の文字を出さない。保存できる量に限りがあるので、まん中の正方形を切り取って 128px に縮めて保存する。画像は敵の向きで回さない(向きは三角で見せる)
- 配置プリセットは、詳細の中のタブではなく、右はしの別のつまみから出る別の引き出しにする(広い画面でもつまみを出し、右の列の上に重ねて開く)
- 元に戻す・やり直す:両方作る。ボタン(フィールドの紫の枠の外の右上。点々の背景の所)とキーの両方。15 回まで。読み込み直すと記録は消える
- 動画で保存:形式は MP4(作れないブラウザでは WebM)・0 秒から最後まで・フィールドにセリフの帯と詠唱のバーも入れる・いつも ×1 で録る・ボタンはヘッダーの右上
