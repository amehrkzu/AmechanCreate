# GIFメーカー(gif-maker.html)

最終更新:2026-11-17。ツール共通の決まりは [Tools.md](Tools.md)

- 動画を入れて、時間と範囲を切り抜き、GIF にするツール(2026-11-17 に作った)。動画はブラウザの中だけで使う(どこにも送らない)
- 1ファイルで完結。`<html data-theme="mikan">` + `ui/kit.css`、`ui/site-header.js`、`ui/scrollbar.css`、`ui/util.js`(`$`・`toast`・`SPINNER`)。レイヤーが無いので `ui/layer-drawer.*` は使わない
- GIF を作る部品は jsDelivr から読み込む(`gifenc@1.0.3`、MIT。絵文字メーカーと同じ)。「GIF を作る」を押したときだけ読み込む
- トップの「ツール」で、絵文字メーカーの次にカード(アイコン:フィルムのコマと再生の三角。説明「動画を切り抜いて GIF にする」)

## 画面
- 左:「動画を選ぶ」と「動画を選択もしくはドラッグ＆ドロップ」(ドロップはページのどこでもよい)→ 動画と切り抜きの四角。その下に「時間」の箱(再生/止める・再生の位置のバー(はじめ〜おわりをバーの下にオレンジで出す)・はじめ/おわり(秒)・「今の位置にする」)
- 右「切り抜き」:比率(自由・1:1・4:3・3:4・16:9・9:16)と、今の大きさ
- 右「GIF」:幅(px)・コマ数(1秒)・速さ(0.5〜2倍)・色数(256〜16)・ファイル名(空なら動画の名前)・作る大きさとコマ数の目安・「GIF を作る」→ できた GIF と大きさ(KB)・「保存」
- 狭い画面では1列(動画 → 時間 → 切り抜き → GIF)

## しくみ
- `crop`(動画の px)、`span`(はじめ・おわりの秒)
- 読み込み:`openVideo()`。長さが分からない動画(ブラウザで録った webm など)は、いちばん後ろへ飛んで長さを出す。はじめの選び方は 0〜5 秒・全体
- 再生:はじめ〜おわりをくり返す(`loopCheck()`)。速さは再生にも効く
- 切り抜き:`.crop-layer` の上で pointer イベント。四角の中=動かす、角=反対の角を止めて大きさを変える、外=新しく囲む(`resizeTo()`。比率があれば保つ)。比率を選ぶと、その比率でいちばん大きい四角を今の四角のまん中に置く(`fitRatio()`)。表示は `showCrop()`(`video.clientWidth / videoWidth` 倍)
- GIF:`gifPlan()` が大きさ(幅は切り抜きの幅まで。高さは比率から)・コマ数を決める。コマの間の動画の時間は `速さ / コマ数(1秒)`、GIF の1コマは `1000 / コマ数(1秒)` ms。`makeGif()` は見ている動画とは別の `<video>` で、1コマずつ `seeked` を待って描き、コマごとに色を選ぶ(`quantize`)。何か変えると、できた GIF は消える(`clearResult()`)
- 覚えるものはない(動画は sessionStorage に入らない)

## 確認のしかた
- [Base.md](Base.md) の「画面の確認」のとおり。ページの中で canvas + `MediaRecorder` でテスト用の webm を作って `openVideo()` に渡し、比率・ドラッグ・時間を変えて `GIF を作る` → `resultBlob` の先頭が `GIF89a`、幅・高さが目安と同じかを見る
