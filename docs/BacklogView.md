# バックログの見える化(backlog.html)

最終更新:2026-10-21

- [Backlog.md](Backlog.md) を、見出しごとの列にして見せるページ(2026-10-21 に作った)
- 1ファイルで完結。`<html data-theme="sora">` + `ui/kit.css` + `ui/site-header.js`(帯なし → 左上に浮く)
- トップの「その他」に カード(アプリダウンロードの次。アイコン:チェックの付いた紙、ピンク)

## 画面
- 上:見出し(`##`)ごとのタブ(パーツメーカーで作ったタグ形のタブ `.ub-backlog-tab`。`.ub-tabs--fill` で横いっぱい。色は見出しの色。選んでいないタブはうすく、選ぶと濃く)。タブに数(`.label`)
- タブの下の箱(パーツメーカーで作った箱 `.ub-backlog-list`。葉っぱの形・点線のふち・白の市松模様・ふんわり影)に一覧。箱は選んだ見出しの色をうすく
- タブを選ぶと、その見出しの一覧が1つ出る。5つまで見せて、6つ以上はスクロール(`.ub-scroll`)。項目の下に、リンク先の md のチップ(GitHub の md を新しいタブで開く)
- 下:「分野ごと」(パーツメーカーで作った箱 `.ub-backlog-areas`。一覧の箱と同じ形で、模様なし・白)= リンク先の md ごとの数の棒。棒は見出しの色で積む
- 見出しの色は順に ピンク・レモン・オレンジ・ミント・ライラック・水色

## しくみ
- 開くたびに `docs/Backlog.md` を fetch して組み立てる(md を直せば、ページは直さなくてよい)。GitHub Pages は md をそのまま返す(確認済み)。file:// で開くと読めない(「読めませんでした」と出る)
- **読む形**:`## 見出し` の下の `- [ ] 文 → [名前](x.md)` の行だけ。`- [x]` は薄く線を引いて出す。見出し・リンクの形を変えると表示が崩れるので、Backlog.md はこの形のままにする
- 文の中の `` `コード` `` と `[名前](x.md)` は表示する。最後の「→ [..](..)」(いくつでも)がチップになる
- リンク先は `DOC_URL`(GitHub の docs/)+ md の名前
- JS:`parse(md)`(見出しと項目に分ける)→ `render()`(タブ・分野ごと)→ `show(i)`(i 番目の見出しの一覧)→ `fitList()`(一覧の高さを `SHOW` = 5 つ目の項目の下はしまでに。画面の大きさ・文字の読み込みで合わせ直す)
