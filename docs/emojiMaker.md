最終更新:2026-11-17。ツール共通の決まりは [Tools.md](Tools.md)

- ディスコードのサーバー絵文字を作るツール(2026-11-13 に作った)。文字を並べる・画像や動く GIF を貼る → PNG(動く GIF があれば GIF)で書き出す。背景は透明
- 1ファイルで完結。`<html data-theme="mikan">` + `ui/kit.css`、`ui/layer-drawer.css` / `.js`(左右の列)、`ui/site-header.js`、`ui/scrollbar.css`、`ui/util.js`(`$`・`esc`・`toast`)
- GIF を読む・作る部品は jsDelivr から読み込む(`gifuct-js@2.1.2` / `gifenc@1.0.3`、MIT)。GIF を使うときだけ読み込むので、PNG はネットがなくても使える
- トップの「ツール」で、レイアウトメーカーの次にカード(アイコン:角の丸い四角のにっこり顔。説明「ディスコードの絵文字を作る」)

## 画面
- 左:「追加」(文字/画像)と「階層」(上が手前。GIF は「GIF」の札)。狭い画面では「☂ レイヤー」の引き出し
- 真ん中:編集の枠(市松模様=透明)。レイヤーをドラッグで動かす。選んでいるレイヤーはオレンジの点線。GIF があると枠も動く
- 枠の下:ディスコードでの見え方。ダークとライトの2つ、それぞれ「文中」(22px)と「単体」(絵文字だけを送ったとき 48px)
- 右「詳細」:文字(文字・並べ方「自動で正方形/改行のまま」・フォント・文字の色・縁取りの色と太さ)、共通(大きさ % 10〜300・横・縦・奥へ/手前へ・消す)
- 右「書き出し」:背景を塗る(チェック+色)・ファイル名・絵の大きさ(128/96/64/48/32px)・GIF があるときだけ「コマを間引く」「色数」(256〜16)・保存ボタン(GIF があれば「GIF で保存」、なければ「PNG で保存」)・大きさ(KB。GIF はコマ数も)。256KB をこえたら赤字で知らせる
- 画像は「画像」ボタン・ドロップ・貼り付け(Ctrl+V)で足す。2コマ以上の GIF は動く GIF のレイヤーになる

## しくみ
- 中の座標はいつも 128 × 128(`SIZE`)。`draw(ctx, S, showSel, t)` が S px に、時間 t(ミリ秒)の絵を描く。編集の枠は 512px(`VIEW`)
- `requestDraw()`:1コマに1回だけ編集の枠を描き直し、`updateOut()` で書き出しの絵とプレビューの `[data-emo]` を作り直す。GIF があれば `tick()` で枠を動かし続ける
- 書き出し:`outOpt`(`size`・`skip`・`colors`)
  - PNG:`drawOut()` が `out` を `outOpt.size` にして描き、`toBlob`
  - GIF:`encodeGif()`。`timeline()` がどれかの GIF のコマが変わる時間でコマを区切る(いちばん長い GIF に合わせ、短い GIF はくり返す。間引くときはまとめたコマの時間を足す)。半透明は使えないので、半分以上見えている所だけ残す(`quantize` の `oneBitAlpha`)。コマごとに色を選ぶ。作るのに時間がかかるので、さわり終わって 250ms 後に作る(`gifTimer`・`gifToken`)
- レイヤー:`{ id, type: "text" | "image", x, y(まん中), scale }`。文字は `text, mode, font, color, stroke, strokeW`、画像は `name, src`(dataURL)、GIF は加えて `frames: [{ src, delay(ms) }]`
  - 文字 `drawText()`:1文字 `UNIT`(100px)で並べ、全体を `128 × scale%`(縁取りの分を引く)の正方形に収まるよう縮める。自動で正方形は字数から `cols = ceil(√字数)`(最後の行はまん中寄せ)。縁取りを全部描いてから字を塗る
  - フォントは Google Fonts(`FONTS`)。まだ読み込んでいない字は `needFont()` で読み込んでから描き直す
  - 画像 `addImageFile()`:長い辺 512px(`IMAGE_MAX`)まで縮めて PNG の dataURL で持つ。大きさ 100% で枠に収まる
  - GIF `decodeGif()`:コマを前のコマに重ねた絵にして(消し方 2・3 も見る)、長い辺 256px(`GIF_MAX`)で持つ。0.02 秒より短いコマは 0.1 秒にする。`frameAt()` が時間からコマを選ぶ
- ドラッグ:`pointerdown` で、選んでいるレイヤーの中なら優先、なければ手前から当たったレイヤー(`l.box`)
- 覚える:レイヤー・背景・ファイル名・`outOpt`(sessionStorage `emojimaker:v1`)。入りきらないときは GIF → ほかの画像の順に外して覚える
