最終更新:2026-11-13。ツール共通の決まりは [Tools.md](Tools.md)

- ディスコードのサーバー絵文字を作るツール(2026-11-13 に作った)。文字を並べる・画像を貼る → 128 × 128 の PNG(背景は透明)で書き出す
- 1ファイルで完結。`<html data-theme="mikan">` + `ui/kit.css`、`ui/layer-drawer.css` / `.js`(左右の列)、`ui/site-header.js`、`ui/scrollbar.css`、`ui/util.js`(`$`・`esc`・`toast`)
- トップの「ツール」で、レイアウトメーカーの次にカード(アイコン:角の丸い四角のにっこり顔。説明「ディスコードの絵文字を作る」)

## 画面
- 左:「追加」(文字/画像)と「階層」(上が手前)。狭い画面では「☂ レイヤー」の引き出し
- 真ん中:編集の枠(市松模様=透明)。レイヤーをドラッグで動かす。選んでいるレイヤーはオレンジの点線
- 枠の下:ディスコードでの見え方。ダークとライトの2つ、それぞれ「文中」(22px)と「単体」(絵文字だけを送ったとき 48px)
- 右「詳細」:文字(文字・並べ方「自動で正方形/改行のまま」・フォント・文字の色・縁取りの色と太さ)、共通(大きさ % 10〜300・横・縦・奥へ/手前へ・消す)
- 右「書き出し」:背景を塗る(チェック+色)・ファイル名・PNG で保存・大きさ(KB)。256KB をこえたら赤字で知らせる
- 画像は「画像」ボタン・ドロップ・貼り付け(Ctrl+V)で足す

## しくみ
- 中の座標はいつも 128 × 128(`SIZE`)。`draw(ctx, S, showSel)` が S px に描く。編集の枠は 512px(`VIEW`)、書き出しとプレビューは 128px の `out` を `toBlob` したもの(見えている絵と書き出しが同じ)
- `requestDraw()`:1コマに1回だけ描き直し、プレビューの `[data-emo]` の画像と大きさの表示も直す
- レイヤー:`{ id, type: "text" | "image", x, y(まん中), scale }`。文字は `text, mode, font, color, stroke, strokeW`、画像は `name, src`(dataURL)
  - 文字 `drawText()`:1文字 `UNIT`(100px)で並べ、全体を `128 × scale%`(縁取りの分を引く)の正方形に収まるよう縮める。自動で正方形は字数から `cols = ceil(√字数)`(最後の行はまん中寄せ)。縁取りを全部描いてから字を塗る
  - フォントは Google Fonts(`FONTS`)。まだ読み込んでいない字は `needFont()` で読み込んでから描き直す
  - 画像 `addImageFile()`:長い辺 512px(`IMAGE_MAX`)まで縮めて PNG の dataURL で持つ。大きさ 100% で枠に収まる
- ドラッグ:`pointerdown` で、選んでいるレイヤーの中なら優先、なければ手前から当たったレイヤー(`l.box`)
- 覚える:レイヤー・背景・ファイル名(sessionStorage `emojimaker:v1`)。入りきらないときは画像を外して覚える
