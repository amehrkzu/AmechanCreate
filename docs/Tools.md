## 共通の決まり
- テーマは「みかん」(オレンジ。アクセント #ff8a3d、枠線 #a8714a、背景 #fff6ee)。キャラカ本体はタブごとに色が変わる([CharacterCard.md](CharacterCard.md))
- 作りかけのデータは、そのタブを開いている間だけ(sessionStorage)。ずっと覚えておくのは、本当に必要なものだけ(例:キャラカのロードストーン ID、オリジナル枠・シンボル、パーツメーカーの保存した形)
- スクロールバーは共通の見た目(`characa/scrollbar.css`。パーツメーカーで作った「スクロールバー」)

## ツールのレイヤーは、サイドバーで管理する(ルール)
このサイトで作るツール(キャラカ・枠エディタ・シンボルエディタ・SVG 系・今後の描画系のツール)は、レイヤー(線・図形・要素)の一覧を、画面の左の「レイヤーのサイドバー」に置く。右のシートや、シートのタブの中には置かない。

### エディタ系の配置(ルール)
- 広い画面(幅1000px以上)では、引き出しにせず**左の列にいつも出す**(UE のヒエラルキーのような配置)
  - 左の上 =「追加」(要素・図形・ツールを選んで足す)。ドット絵メーカーは道具を選ぶ欄なので「ツール」
  - 左の下 =「階層」(レイヤー一覧)
  - 右 =「詳細」(選んでいる物の設定。何も選んでいなければ空)。キャラカの「デザイン・キャラ・エフェクト・カード」など、選択に関係ない設定は右の別タブ
- 狭い画面では、左も右も前面に出る引き出しになる(左 = つまみ「☂ レイヤー」、右 = つまみ「✿ 詳細」/キャラカは「✿ 設定」。右は `ui/layer-drawer.css` の `.right-drawer`・`.right-handle`)
- 左の列は**1つの箱**(`<section class="box"><h2>追加</h2>…<h2 class="next">階層</h2>…</section>`)にして、箱ごとスクロールする(追加と階層を別の箱に分けると、階層が押しつぶされて見えなくなる)
- **スマホの大きさでは、サイドバー(左右とも)をなるべくスクロールさせない**。入りきらないときは、この順で考える:① サイドバーの中をタブに分ける → ② タブに分けられないときだけ、スクロールでよいかユーザーに聞いてから決める
  - **サイドバーの中のタブは、キャラカのような付箋タブ(パーツ台帳の `.sheet-tabs` / `.sheet-tab` と、下の紙 `.sheet-body`)を基本にする**。選んだタブが飛び出して下の紙とつながり、タブごとに色(`--c`)を変える
  - **サイドバーのスクロールバーは、キャラカのようなスクロールバー**(`characa/scrollbar.css`)にする
  - 右のタブは `ui/layer-drawer.*` の `.right-tabs`(`<button role="tab" data-tab style="--c:色">` と、箱の `data-panel`)。付箋タブで、すぐ後ろの列が紙(選んだタブの色を薄くしく)。狭い画面だけタブになり、広い画面では箱を全部ならべる。幅400px以下は文字を小さく
  - 今(2026-10-22):SVGメーカー・ドット絵メーカーの右は、箱1つ=タブ1つで、幅320〜375px でも収まる。枠エディタ・シンボルエディタは何も選んでいなければ収まる。キャラカは後回し
  - 次の候補:引き出しになるのは幅 999.98px 以下なのに、エディタが1列になるのは 900px(枠エディタ)/ 860px(SVGメーカー)以下。その間の幅で崩れないか、ヘッドレス Chrome で確かめる

### 見た目と動き
- 左のサイドバーは、画面の左と上の帯に**すき間なくくっつける**(広い画面は `.app` の padding 14px を負の margin で打ち消す)
- 左のサイドバーはテーマ「そら」(水色)、四角い角・枠線なし・ぷっくり影・ふわっと。いつも見えている付箋のつまみ「☂ レイヤー」を押すと出し入れ(開いても閉じても同じ水色)。開いているかは、そのタブを開いている間だけ覚える
- 新しいツールは、`ui/layer-drawer.css` と `ui/layer-drawer.js` を読み込み、`<aside class="layer-drawer" id="layerDrawer">` の中に、上の1つの箱と `<button class="layer-handle" id="layerHandle">☂ レイヤー</button>` を置く(書き方は `ui/layer-drawer.js` の先頭のコメント)。一覧の行は `.layer-list li`(選んでいる行は `.on`)にすると、水色に合う
- 対応状況:枠エディタ・シンボルエディタ・SVGメーカー・ドット絵メーカー(レイヤーは1枚なので、左の下は「色」)は `ui/layer-drawer.*` を使う。キャラカは自前の同じ見た目(`characa/style.css` の `.layer-drawer`)
- 同じ名前のサイドバーの部品が、パーツメーカーの「サイドバー」(`ui/kit.css` の `.ub-drawer`)にもある

## 画像の書き出し(相談済み)
- PSD の読み書きはブラウザでもできる(`ag-psd`)が、文字・効果・CMYK で崩れやすいので、**作らない**ことにした(2026-10-21)。入稿データは Photoshop で作る。必要なら「グッズの大きさ・350dpi に合わせた PNG 書き出し」を足す
