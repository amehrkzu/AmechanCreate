# キャラカ 作業の記録

最終更新:2026-10-21。今の仕様は [CharacterCard.md](CharacterCard.md)。新しい記録は末尾に1行で足す

## いつ何を作ったか
- 2026-10-01:Lodestone の調査 → 方針を「GitHub Pages + Cloudflare Worker」に決定。`worker.js` を作ってデプロイ。カード UI の初版(canvas 直描き・テキスト/画像/図形/ジョブ一覧・差し込み項目・ジョブアイコン)
- 2026-10-02:Lodestone の画像は使わず、スクショを土台にする方針に。デザイン5種と配色7種、スクショのエフェクト、UI をパステルに、制作エリアの拡大縮小・移動(全体表示は 1920×1080 が収まる倍率 ×0.94)、辺・角のドラッグで大きさ、スマホ向けの画面の構成
- 2026-10-08:枠エディタ(角の飾り・辺の模様・土台の角・枠線、切り抜き、レイヤーの並べ替え)、シンボルエディタ、アイコンメーカー(SVGメーカー)。魔獣使いのアイコンを描き直し
- 2026-10-13:基調の色をオレンジ(みかん)に。作りかけのカードを sessionStorage に(ずっと残すのはロードストーン ID とオリジナル枠・シンボル)
- 2026-10-14:レイヤーのフォルダー、レイヤーは左のサイドバーに、シートのタブごとの色、エフェクトタブ、リセット、共通のスクロールバー、表示を動かしても選択を外さない。GitHub Pages に公開(Worker の許可にも追加)
- 〜2026-10-21:エディタ系の配置(左=追加+階層、右=詳細。狭い画面は左右とも引き出し)、タブの並びを「詳細」から、ジョブ一覧を列数なしの折り返しに、メインジョブ・時間帯・コンテンツを別の要素に、フォルダーの中にフォルダー、「図形」を「枠」にして枠の形を1つずつ選ぶ(カード全体の枠の形はなくした)、線の太さの欄、Shift+ドラッグで表示を動かす

## 調べて決めたこと(2026-10-01)
- Lodestone のキャラページはログインなしで読めるが、`Access-Control-Allow-Origin` がないので、ブラウザから直接は読めない → サーバー(Worker)が要る
- 公開の CORS プロキシ(allorigins)は落ちていて、XIVAPI は Lodestone に 403 でブロックされていた → 第三者のサービスは使わない
- 競合サイト(characa.kkimu.dev・knt-a.com/c-card)は、どちらも自前のサーバーで取っている(他人の API は無断で使わない)
- Cloudflare Workers の無料枠(1日10万リクエスト、クレカ不要、超えてもエラーになるだけ)で足りる。Cloudflare の IP から Lodestone を読めることも確認済み。使う人はログイン不要
- ブックマークレット・手入力だけの案は、使いにくい・便利さがないのでやめた
