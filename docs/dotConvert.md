# ドット変換(dot-convert.html)

最終更新:2026-10-27。ツール共通の決まりは [Tools.md](Tools.md)

- 絵を、ドット絵みたいな見た目に加工するツール(2026-10-27 に作った)。いわゆるモザイク
- ユーザーの希望:**大きさは元のまま・色は減らさない**。ドット絵っぽく見えればよい
  - 粗さは px ではなく「横に何ドット並ぶか」で決める(大きい絵でも同じドット感になるように)
  - ブロックの色は平均の色(「まん中の1点」との切り替えは要らない、とのこと)。アンチエイリアスを消したいときだけ、チェックで「くっきり」にする
  - 最初に出した案(マス数に縮める・色を減らす・パレット・ディザ・輪郭・ノイズ消し)は、いったん不要
- 1ファイルで完結。`<html data-theme="mikan">` + `ui/kit.css`、`ui/layer-drawer.css` / `.js`(右の列だけ)、`ui/site-header.js`、`ui/scrollbar.css`、`ui/util.js`(`$`)
- トップの「ツール」で、ドット絵メーカーの次にカード(アイコン:マスに区切った四角。説明「ドット絵みたいに絵を加工する」)

## 画面
- 広い画面:真ん中の枠 / 右の列。狭い画面では右の列は「✿ 詳細」の引き出し(箱が2つなのでタブなし)
- 真ん中の枠は**決まった大きさ1つ**(画面の高さいっぱい。絵の形で変わらない)。絵は枠に収まるいっぱいの大きさでまん中、余白は白、市松模様は絵の部分だけ(ユーザーの希望。2枚並べると見づらい)
- 真ん中の上:「元の絵/ドット」の切り替え(読み込んでから出る。最初と、読み込むたびにドット)
- 枠のすぐ下の右端:画像を読み込む(絵には重ねない、とのこと)。読み込む前の枠の中は点線(押しても読み込める)。ドラッグ&ドロップ・貼り付け Ctrl+V でも
- 右の「ドットの粗さ」:チップ 32/48/64/96/128、スライダーと数字(横のドット数 16〜256。最初は 64)、「横 × 縦 ドット(1ドット ○px)」、チェック「色をくっきり」「透明をくっきり」(最初はどちらもオフ)
- 右の「書き出し」:ファイル名(読み込むと「元の名前_dot」)、PNG で保存、大きさ(元の絵と同じ)

## しくみ
- 横のドット数 `dots` から、縦は縦横比で決める(`gridSize()`。元の絵の px より細かくはしない)
- `edges(n, total)`:n ブロックを total px に分ける整数の境目(ドット絵メーカーと同じ考え)。割り切れなくても、ブロックが 1px ずつちがうだけで端に余りが出ない
- `convert()`:ブロックの横1列ずつ、色を足し合わせて平均し、`ImageData` に直接書く(`Uint32Array` で1px ずつ)。結果のキャンバスは元の絵と同じ大きさなので、保存はそのまま `toBlob`
  - 平均は `averageRow()`。**不透明度の重み付き**(透明なところの色がまざって黒っぽくならない)。不透明度はブロックの平均
  - 色をくっきり(`crispColor`):`modeColor()`。RGB を 32 段ずつの組(`BINS`)にまとめて不透明度の重みで数え(グラデーションはまったく同じ色がほぼ無いため)、**一番多い組**の中の平均の色で塗る。組の数は、となりの組(RGB それぞれ ±1 段)も足して比べる(同じ色が組の境目で分かれて少なく数えられ、線のふちの中間の色が選ばれて汚くなったため)。
    - 「25% 以上の組のうち少ないほう(目立つ色を優先)」も試したが、線のふちの中間の色が選ばれて汚くなったのでやめた(2026-10-27)。そのため、ブロックの境目に半分ずつかかる線は欠けることがある使った組だけ 0 に戻す(`touched`)
  - 透明をくっきり(`crispAlpha`):`pack()` で、不透明度の平均が 128 以上なら不透明、それより下は透明
- 覚えるのは `dots`・`crispColor`・`crispAlpha`(sessionStorage `dotconvert:v1`)。絵は覚えない
- 画面の表示は CSS で縮めるだけ(`image-rendering: pixelated`)。書き出しには関係ない
- スライダーを動かしている間は `requestConvert()` で1コマに1回だけ変換。4000×3000 でも約 60ms
- 表示の切り替え:`setView("original" | "result")`(`#original` と `#result` の hidden を切り替える)
- 読み込み:`loadFile(file)`(`Image.decode()` → キャンバスに描いて `getImageData` を `src` に持つ)
