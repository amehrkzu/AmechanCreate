# /ok:了承された作業を進めて、終わりに確認する

ユーザーが /ok を打つと、Hook(`.claude/hooks/task.js prompt`)が「作業中」の目印を作る。目印があるあいだだけ、このフォルダーのファイルを書き換えられる。

## 手順
1. **何をするか**:直前に確認の形で出した作業。/ok のうしろに文があれば、それも合わせる。分からなければ、書き換える前に短く聞く(聞いて待つときは `node .claude/hooks/task.js wait` を実行してから終える)
2. **作業する**:[docs/Base.md](../../../docs/Base.md) の決まりとコード規約どおりに。ページ・しくみを変えたら、同じ作業の中で、その md も直す
3. **書き出す**:この作業で見つけたこと・後回しにしたこと・ユーザーに出した「次の候補」を全部書き出す。会話で言っただけのものも入れる。1つずつ、[docs/Backlog.md](../../../docs/Backlog.md) とリンク先の md の両方にあるか確かめて、無ければ足す。片付いたものは両方から消す
4. **確かめる**:`node .claude/hooks/task.js done --review "3. で足した・確かめたもの(無ければ なし)"` を実行する
   - 「直し忘れかもしれないもの」が出たら直して、もう一度実行する
   - 直さなくてよいもの(md に書くほどではない小さな直し など)は `--skip "理由"` を付ける。理由は報告にも書く
5. **報告する**:変えたファイル、Backlog.md に足した・消したもの、`--skip` の理由を日本語で短く書く。コミット・プッシュはしない、すすめない

## 注意
- 目印(`.claude/state/`)は自分で作らない・消さない。消すのは `done` だけ
- 目印を消すと、次の /ok までファイルを書き換えられない。続けて直したくなったら、内容を伝えて /ok を待つ
