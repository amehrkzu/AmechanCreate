AIへの頼み方

  • まずテーマを言う:「そら」で作って(水色) / 「いちご」(ピンク) / 「みかん」(オレンジ)
  • 部品は名前で:上に「大見出し」、その下に「リンクカード」を3つ。いちばん下に「注意書き」
  • 色も名前で:このアイコンは「付箋・ミント」
  • 見本帳にない部品を作ったら、名前を決めてこの見本帳にも足してもらう
  • ボタンの形や色を自分で決めたいときは パーツメーカー で作れます
  • 各部品の「コードを見る」で HTML を確認・コピーできます

テーマと色

テーマは <html data-theme="sora"> で決めます(ichigo / mikan)。上のボタンで切り替えて見比べられます。色を押すと CSS の書き方をコピーします。
